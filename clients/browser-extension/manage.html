Локальный UniMem

Материалы и задания

Выберите «YouTube → Markdown» в меню значка на странице ролика. Обычный клик сохраняет выделенный текст; «Сохранить всю страницу» — HTML страницы.

Подключение

Адрес сервера: http://127.0.0.1:8765

Получите токен командой python -m unimem_api --data-dir ./data --show-token. Для субтитров запустите сервер с --youtube.

Токен не показывается повторно. Пустое поле сохраняет только порядок языков.

По умолчанию токен хранится до завершения сеанса браузера. Постоянное хранилище не зашифровано; другие программы вашего пользователя могут прочитать профиль.

От 1 до 10 кодов через запятую, в порядке выбора. Перевод не выполняется. Изменения применяются к новым заданиям.

Загрузить аудио

Локальная автоматическая расшифровка: WAV с PCM, MP3, OGG с Opus. До 32 МиБ и 120 секунд; одна аудиодорожка, 1–2 канала, 8–48 кГц. Поддержку проверяет сервер по содержимому. Аудио сохраняется в UniMem; в Obsidian отправляется текст.

Оператор один раз подготавливает модель, затем запускает UniMem с --audio-model. Здесь модель не скачивается.

До подтверждённого приёма не закрывайте страницу. После приёма сервер продолжит работу самостоятельно.









Операции YouTube
До 50 локальных ссылок. Задания выполняет сервер; закрытие этой страницы не отменяет принятые операции. Повторный выбор того же ролика открывает существующее задание. Для нового захвата есть «Сохранить заново».



Выбранное задание




«Повторить доставку» проверяет прежний ID и отправляет те же параметры только при неподтверждённом приёме. «Сохранить заново» создаёт новый ID и новый захват. Удаление ссылки не отменяет работу и не удаляет серверный capture.
